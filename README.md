# Personal Portfolio — Web Programming Phase 1

## Website Structure
This project is a responsive personal portfolio containing:
- Home
- Profile
- CV
- Education & Technical Expertise
- Projects
- Activities/Gallery
- Contact

## HTML5 Features
- Semantic elements: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Headings, paragraphs, links, images and lists
- CV/Education table using `caption`, `thead`, `tbody`, `tr`, `th`, and `td`
- Contact form with text/email inputs, select, radio buttons, checkbox, textarea and button
- HTML5 multimedia demonstrated using an `audio` element
- SEO/meta tags including viewport, description, author and keywords

## CSS Features
- External stylesheet
- Element, class and ID selectors
- Box model, padding, margin, borders and shadows
- Typography and consistent spacing
- CSS Grid and Flexbox
- Responsive media queries for desktop, tablet and mobile

## GitHub Pages Deployment
1. Create a GitHub repository, e.g. `personal-portfolio`.
2. Upload `index.html`, `style.css` and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` branch and `/ (root)`.
6. Click **Save**.
7. Wait for GitHub Pages to publish the site.
8. Your URL will normally be:
   `https://YOUR-USERNAME.github.io/personal-portfolio/`
